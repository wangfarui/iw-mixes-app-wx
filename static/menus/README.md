# 菜单图标来源

本目录的 19 个 SVG 用于 `pages/menu`，对应 2026-10-21 确认的图标方案；“食谱”使用封面带餐具的菜谱本。

图标路径来自 iconfont 页面实际展示的 SVG，仅移除页面展示属性并应用分组颜色；不依赖在线字体或远程图片。原始路径和透明度保留，尺寸为 48 × 48，页面用 `aspectFit` 展示。分组浅色底定义在 `pages/menu.wxss`。

来源：

- [迈鼎icon 图标库](https://www.iconfont.cn/collections/detail?cid=51731)：除下述三项外的图标。
