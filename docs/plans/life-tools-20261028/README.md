## 2. 页面和产品行为

### 2.1 菜单入口

保留现有两列网格和其余四个业务分组，原「基础功能」位置替换为：

| 第一列 | 第二列 |
| --- | --- |
| 心愿清单 | 重要日期 |
| 收藏夹 | 应用账号 |

使用同一套线性图标和淡蓝灰底色，分别为爱心、日历、星标、账号卡。正式使用本地 SVG，草图的字符图标只用于说明位置。菜单搜索继续匹配功能名称，兼容「账号管理」旧搜索词。

「应用账号」沿用已有业务、页面路径、数据表、密码加密与查看行为；统一菜单名称、列表标题及编辑页的「新增应用账号／编辑应用账号」等上下文名称。「账号安全」仍代表当前登录账户安全，不改名、不合并。

### 2.2 心愿清单

记录想买、想体验、想完成的事；金额可选，不限于购物。

- 默认显示「想实现」，另有「已实现」「已搁置」。支持标题、备注搜索。
- 列表显示名称、预计金额（填写时）、优先级、目标日期（填写时）和备注摘要。
- 新增字段：名称必填；预计金额、目标日期、参考链接、备注选填；优先级「慢慢来／优先实现」，默认慢慢来。
- 排序：优先实现优先；同优先级有目标日期的按目标日期升序，无日期在后；最后按创建时间和 ID 倒序。
- 状态：想实现可「标记已实现」或「搁置」；已实现、已搁置均可「重新加入心愿」。编辑、删除在编辑页操作。
- 标记实现记录完成时间，重新加入清除当前完成时间。搁置保留原始内容，不等于删除。
- 顶部只展示待实现数量，避免把体验类心愿和购物预算混成余额或储蓄进度。
- 标记实现不会自动记账，不改变钱包、预算、积分。参考链接仅手动保存和复制。

### 2.3 重要日期

用于生日、纪念日、到期事项等，以「还有几天／今天／已过几天」为核心。

- 默认「即将到来」展示未来 30 天（含今天）的日期；「全部」包含更远的日期和已过期的一次性事项。
- 名称、类型、历法、日期、重复方式、应用内提示、备注构成编辑表单。类型为生日／纪念日／到期事项／其他。
- 名称和日期必填；公历使用日期选择器，农历使用年、月、日联动选择器；日期必须真实存在。所选年份只显示真实存在的闰月，天数跟随月份变化。
- 重复支持「不重复／每年」；生日和纪念日默认每年，到期事项和其他默认不重复，可调整。
- 提示支持「不提示／当天／提前 1 天／提前 3 天／提前 7 天／提前 30 天」，默认当天。
- 列表同时显示原始日期、下一次对应的公历日期、剩余天数和提示状态，按下一次日期升序、ID 倒序排列。
- 每年重复事项在当天仍显示「今天」，次日才切换到下一年；过期一次性事项只在「全部」显示「已过 N 天」，可编辑、删除。
- 原始年月日长期保留，换算结果不覆盖原始农历日期。具体闰月、月底和边界规则见 [技术约束](TECHNICAL.md)。

建议本次提示采用应用内展示：进入菜单时「重要日期」入口显示正在提示的事项数量；进入日期列表时相应事项显示「今天／临近」。提示有效期是目标日前 N 天至当天，关闭提示的事项不计数。没有后台通知发送任务，不默认接入微信订阅消息、短信或邮件。因此用户不打开小程序时不会收到主动提醒。此项为建议范围，若需要主动微信通知，需另行确定订阅授权、模板与发送链路，不能把应用内提示当作已具备推送。

### 2.4 收藏夹

保存值得回看的链接，适用于网站、文章、视频等。

- 搜索标题、链接、备注；按「全部／网站／文章／视频／其他」筛选，类型默认其他。
- 新增表单：名称必填，链接、类型、备注选填；可以只填写名称保存。可从用户主动操作的「粘贴链接」填入，不在进页时自动读取剪贴板。
- 列表显示名称、类型和备注摘要；填写链接时才显示来源域名。轻点进入编辑页，可修改、复制、删除。
- 支持置顶／取消置顶。置顶记录先显示，同组按创建时间和 ID 倒序。
- 列表操作区只保留一个「置顶／取消置顶」按钮，移除「复制链接」；点击记录仍可编辑内容。
- 链接只接受 HTTP/HTTPS；不擅自修改 query、path 或 fragment，保留用户保存的原链接。相同链接允许重复收藏，不做隐蔽合并或覆盖。
- 与已有「网站导航」分表分接口，避免个人收藏进入现有公开共享导航查询。

### 2.5 公共交互与视觉

三个新工具统一采用搜索、筛选、紧凑列表和底部固定新增按钮。列表支持下拉刷新和触底分页；列表项与金额之间保持稳定间距，金额不换行，长名称、长链接、长备注可断行。底部留安全区，空态只保留一处。

正式新增／编辑使用独立页面，避免农历选择、长备注与软键盘同时挤在弹层内。草图为便于并排评审，以弹层模拟编辑页；这不代表最终弹层方案。点击保存期间按钮禁用；返回有未保存内容时提示「继续编辑／放弃修改」。删除二次确认。提交失败保留表单，列表加载失败保留已加载内容并提供重试。

应用账号继续沿用现有样式。本次不重做账号功能或「我的」页，不增加新的底部 Tab、生活工具中转首页或通用设置组。
