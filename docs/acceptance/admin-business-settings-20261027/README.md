## 最终实现

- 厨房设置新增管理员系统分组：菜品分类、用餐时间、菜品状态；记账设置新增：收支类型、订阅计费周期、订阅周期单位。普通用户保留原有个人/家庭设置。
- 六类固定项以真实业务枚举为唯一支持清单，提供查看、差异预览、按类确认同步；不自由新增、改名、删码、启停或排序。模板与非删除用户副本按稳定编码校准，保留既有ID和编码。
- 后端明确只给系统ADMIN=10、SUPER_ADMIN=20授权，不能由家庭身份推定权限。超管系统设置提供六类全量修复预览；每次写入重新鉴权、校验预览版本并在数据库互斥锁内提交。异常数据阻止写入，不静默删除或映射。
- 同步提交后的缓存错误允许仅重试缓存。版本原子递增保持数字协议；本轮真实验收发现首次递增的小整数被严格Long读取拒绝，已兼容Number并回归小整数/长整数读取。
- 移除小程序/Web字典维护菜单，旧页面保留业务迁移指引；通用写API关闭六类固定项及内部模块标记。普通业务候选读取保留，个人/家庭选项不被管理员同步覆盖。
- 本轮修正异常按钮文案为“存在异常，暂不可同步”，并用显式四边定位兼容原生底部确认弹层。

1. 家长在真实小程序中预览并确认同步订阅计费周期：校准16条，随后差异为0，缓存刷新成功。
