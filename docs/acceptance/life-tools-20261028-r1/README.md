## 实施范围

- 小程序：[菜单](../../../pages/menu.js)将「基础功能」改为「生活工具」，提供心愿清单、重要日期、收藏夹、应用账号四个入口。旧搜索词「账号管理」仍可找到应用账号，原账号接口与页面路径保留。
- 小程序：[pagesLife](../../../pagesLife/life/list-page.js)提供三个工具的列表、搜索筛选、编辑和状态操作；[api/life.js](../../../api/life.js)接入既有认证请求。日期支持公历、农历、每年重复及应用内临近提示，不发送微信消息。
- 后端：[iw-life](../../../../iw-mixes-server/iw-packaging-parent/iw-life/README.md)由 `iw-core` 聚合，三个新表按认证用户隔离，提供版本冲突检查和新增请求去重。日期计算使用项目现有 Hutool，并以独立历法样本检查。
- 后端 `scripts/local-backend.sh` 支持明确指定 JAR，默认选择最近构建的包，避免字典序选中旧包；[选择规则测试](../../../../iw-mixes-server/scripts/test-local-backend-jar.sh)通过。
- Web 管理端无改动。生产数据库和生产环境未变更；代码未提交、未推送、未发布。
